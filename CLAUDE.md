## Project

"Kurczacze Imperium": PL3Y card-drafting game for **2 players in two separate browsers**, or one player against the server bot „Kogut Zenek” (desktop-first, phone not a priority). Static HTML/JS, no build step, served at `https://pl3y.pl/kurczacze/` (repo `egozaur/kurczacze`). Work happens on two machines: **macOS** (Python 3, Node, Chrome; no PowerShell) and **Windows** (no Node or Python; PowerShell 5.1, Edge). Check which one you are on and use the matching command below. The author's source material (rules PDF, xlsx, JSON) lives outside the repo in `Desktop/PL3Y/Kurczacze-imperium/`; don't read the PDFs, this file summarises them.

The mechanics are the author's own variant of a known 2-player drafting genre; names, cards and texts are original. Keep the look PL3Y's own (black and gold like the lobby); don't imitate any commercial game's card art or iconography.

**Status:** engine, server, protocol, tests and the first version of the real UI are done. In the lobby carousel (`GAMES` in `../egozaur.github.io/index.html`, preview `pyramid`; a thumbnail `/img/kurczacze.webp` can be added there later, until then the CSS pyramid shows). Illustrations of cards, wonders and Discoveries are JPGs in `img/` named by data id (`J-01.jpg`, `C-01.jpg`, `O-01.jpg`; `artPic(id)` in icons.js), cut from the author's Gemini sheets `ku-gra/arkusze/a1..a17.jpg` (generated names/numbers cut off; cards 400×500 = 4:5 like the art field, wonders 720×405, Discoveries 320×320; card art fills the field with `object-fit: cover`). ## UI files
- `index.html` + `app.js`: screens menu (create / „Graj z Kogutem” with level chips Łatwy/Średni/Trudny, remembered in `kurczacze_bot` / join by code) → invite link `#CODE` asks for a nick → waiting room (code, copy link, seats, host picks the turn timer, start) → table. The table is a fixed 1920×1080 `#stage` scaled to the window (`fit()`), laid out like `noweui.png`: top bar (logo, Era + whose move, timer, connection, „Zasady” (rules summary) and „Legenda” (every icon with its name) windows from `help.js`, `⚙` room info, Lobby), opponent row on top and yours at the bottom (player panel 400 px with avatar/ribbon/coins/feathers/symbols/production, empire columns on a landscape with card width fitted to the number of colours, wonders 2×2 under a „Cuda (name)” label), war track on the left (nest images, rooster moves up toward the opponent), Era banner + layout in the middle (card size fitted per Era; green glow = you can afford it, gold = selected, round price coin under free cards), right column = tabs Karta / Cuda / Nauka / Wojsko (`ui.tab`; Karta = preview, hover shows a preview over any tab, a clicked card/wonder/Discovery stays pinned there (`ui.pin`) until another is clicked; a selected free card shows status, ZBUDUJ KARTĘ, Odrzuć, „Wsuń pod Cud” toggling the wonder list `ui.tuck`), Discoveries on the board, history with icons (+ full-history window). Overlays: pending choice, end screen, bar windows (`ui.dlg`). „Lobby” goes to `/` (the seat token stays, the same link resumes).
- `help.js`: content of the Zasady and Legenda windows (numbers read from `DATA.rules`). Icons carry hover tooltips (`title` / SVG `<title>`).
- `cards.js`: `cardHTML(id, 'mini'|'full')`, `backHTML(era)`, `wonderHTML(id, size, extra, cls)`, `tokenHTML`, effect icons from the data (`effectHTML`). Card internals are sized in `cqw` (the card is a size container), so one template works at any width: set `--cw` (cards) / `--ww` (wonders) / `--kt` (tokens) on the parent. Don't use `cqw` on `.kc`/`.kw` themselves (it would resolve against the viewport).
- `icons.js`: `icon()`/`sym()` return the author's PNGs for the 5 resources, 7 science symbols and coin/feather/spur (`img/ui/i-*.png`; `coin(n)` = coin picture + light centre + number), all cut from the author's sheet `Kurczacze-imperium/newicon.png` (painted checkerboard removed by flood fill, 256 px, transparent) (`pic(id)` = URL in `img/`, resolved from the module so `dev/` pages work); hand-drawn SVG for the rest (coin with number, feather, spur, nest, wonder, 7 science symbols, 16 chain symbols, era egg).
- `style.css`: colour tokens and all components.
- `fx.js`: animations ("2.0"), client only, no server changes. In `onState`: `snap()` (rects + HTML of slots, empire cards, wonders, board tokens, draft, loss tokens, rooster) → `diff(oldV, newV)` (what happened, derived purely from the two views: build/discard/tuck/destroy/steal, pick, token, reveal, track, coins/VP, symbols, era, end…) → `begin(E)` → render → `play(E, S)`. Copies ("ghosts") fly on `#fx`, a layer outside `#stage` with the same transform (`FX.fit()` in `fit()`); targets are hidden meanwhile by classes kept in `marks` and re-added by `FX.reapply()` at the end of `renderStage()`. A new state stops the running sequence and shows the final state; clicks always work. Pending-choice / end overlays get `fx-wait` while `FX.holding()`. Needs `data-p` on `.area`, `data-coins`/`data-vp`, `data-sym`, `data-i` on slots, `data-loss`. Off for the first state after load/reconnect, `prefers-reduced-motion`, a hidden tab, `?nofx`, or the ⚙ setting (`kurczacze_fx` = on/fast/off). The 10 effects: build (arc flight + stamp, coins, gold chain trail), discard (burn + ash, +N coins), tuck (card slides under the wonder, colour wave + stamp, 6th wonder cracks the rest), reveal flips, coin/feather flows + count-up, rooster hops with spurs and cracking loss tokens (KUKURYKU at field 7), science (symbol pop, pair shake, Discovery spins to the panel), draft fan-in / boxed wonder / Era banner with a hatching egg + deal, turn ("Twój ruch!", ribbon bounce, opponent's card glows red with their name, timer pulse), end (rows + count-up, crown and feather rain / one sad feather).

## Bot mode („Graj z Kogutem”)
- Menu: nick + level → `KI.createRoom({bot})` → `autoJoin` makes `route()` join the new room at once; no waiting room or invite link. The player always sits at seat 0, the bot at seat 1 (`seats[1] = {name: 'Kogut Zenek', bot: level}`, no token, always „online”). Rematch works as usual; the end screen adds „Inny poziom” (back to the menu). UI: gold tag „Bot · <poziom>” on the opponent's panel (`.botb`), top bar shows „Kogut Zenek myśli…” instead of „Ruch:”, the ⚙ window shows the bot level and hides the time limit and the room link.
- Server (`room.js`): `init(code, {bot})` (unknown level = ordinary room); the human's `hello` starts the game immediately (`newGame()`). When `E.actor(g)` is the bot, `arm()` sets `deadline` to now + `BOT_DELAY` (1–1.5 s, so the client's fx animations stay readable) and `alarm()` plays `botMove(E.view(g, seat), level)` via `E.apply` (fallback `timeoutMove` if it ever fails). The human's turn timer is unchanged (no deadline without a limit; `view.left` is 0 during the bot's turn). `room.rand` (bot randomness + delay) can be replaced in tests.
- `worker/src/kurczacze/bot.js` (pure): `botMove(view, level, rnd)` → act; the bot sees only `E.view(s, seat)` (prices from `slots[i].price` / `wonderPrice`). `rebuild(view)` turns the view into an engine state: face-down cards and later Era decks are sampled from cards it has not seen (`s.guess` = unknown slots, `s.pool` = unseen cards), `since = -1` (exact at decision time), hidden VP (Tajemnica Łańcucha, Gniazdownictwo) recovered from `view.players[i].vp`. Levels: **easy** random legal move; **medium** simulates every move 1 step and scores it with `evaluate` (VP, coins, production per Era, science and war threats, chains, tokens; weights `W0`) minus the opponent's `tempo` (immediate military/science win incl. the risk of revealing one from the unseen pool, best visible card) — covers draft, build/discard/wonder and pending token/grab/destroy/steal; **hard** = top 6 medium moves × 3 samples of hidden cards × every opponent reply (minimax), with weights `W_HARD` (W0 auto-tuned by medium-vs-medium self-play). Work is capped by a clone counter (`BUDGET`), not by time (the Worker clock stands still during CPU work); hard averages ~3 ms per move, max ~30 ms.
- Measured (pairs of seeds, swapped seats): medium beats easy ~93%, hard beats medium ~75%, hard beats easy ~95%.

## Rules (as implemented)
- 3 Eras (Jajka, Pisklęcia, Koguta), 18 cards each laid out in rows (layouts in `DATA.rules.layouts`, rows alternate face-down/face-up, bottom row face-up). A card is free when no card of the row below covers it; in Era 3 the two middle rows of 4 cover only the card directly below.
- Setup: random first player, coins 6 / 7. 4 of 8 Discoveries on the board. Wonder draft: two sets of 5, pick order A B B A / B A A B, the 5th goes back to the box; 4 each, max 6 built in the game (the 6th removes all unbuilt ones). Each Era deck drops 3 random cards; Era 3 gets 3 random of the 6 Guilds (purple).
- Turn: take a free card and **build** it (coins + resources), **discard** it (3 + 1 per 2 own yellow cards), or tuck it under one of your **wonders** (pay the wonder's cost).
- Resources are not consumed. Missing ones are bought: 1 + 2 × the opponent's fixed production of that resource on brown/grey cards (choice production doesn't raise the price). Yellow "fixed price" cards: that resource costs 1, **from the next turn**. Choice production (incl. Kurzy Bazar, Fontanna Rosy) works immediately. Chain symbol (Ślad Pazurka): build free.
- War: each Ostroga moves the rooster 1 field toward the opponent; track ±7. First entry to field 3 / 5 on the opponent's side: they lose 3 / 6 coins (once each). Field 7 = immediate military win. End VP 2/4/8 for fields 1–2/3–4/5–6.
- Science: a pair of the same symbol = pick a Discovery from the board (if any left); 5 different symbols = immediate win. Zegar Piania and Jajo Wszechświata have one card each; Waga Ziarna only from the Kodeks Grzędowy discovery.
- Next Era starts with the player the rooster stands toward (weaker); rooster at 0 = the player who didn't make the last move. An extra turn from a wonder built with the last card of an Era is lost.
- Civil end: VP from cards, war, guilds, wonders, discoveries, chain bonus, 1 per 4 coins. Tie: more built wonders, then more coins, then both win.
- Author's decisions / assumptions: extra turn at Era end is lost; choice production works immediately; Kurzy Bank counts the card being built; effects without a target (no yellow card to destroy, no board discovery) do nothing; a destroyed yellow card loses its fixed price.
- Optional turn timer (0/60/90/120 s, host sets it): on timeout the server makes a default move (first wonder / discard first free card / first option).

## Code
- **Server** (sibling repo `../mafia`, only these files matter): `worker/src/kurczacze/data.js` (generated from the author's JSON; regenerate, don't edit), `engine.js` (pure engine: `setup`, `apply`, `timeoutMove`, `view`, prices `cardPrice`/`wonderPrice`/`tradeCost`, `scores`), `room.js` (DO `KiRoom`: 2 seats, tokens, turn-timer alarm, bot turns, rematch), `bot.js` (bot, see above). Routes `POST /api/ki/rooms` (optional JSON body `{bot: 'easy'|'medium'|'hard'}`), `GET /api/ki/rooms/:code/ws`. Tests `worker/test/kurczacze.suite.js` (incl. 200 bot-vs-bot games, win-rate thresholds medium ≥ 75% vs easy and hard ≥ 60% vs medium, hard speed, bot room alarm).
- `view(s, p)` is the only place that decides what leaves the server: never face-down layout cards, removed deck cards, unused guilds, boxed discoveries or the RNG state. Free slots carry `price[0|1]` (`{coins, chain, ok}`), so the UI never computes rules.
- Protocol: `→ {t:'hello', join:nick | player:token}`, `{t:'cfg', time}` (seat 0), `{t:'start'}` (seat 0), `{t:'move', id, act}`, `{t:'rematch'}`; `← {t:'welcome', seat, token}`, `{t:'state', view}`, `{t:'error', code, err}`. Moves: `{a:'pickWonder', wonder}`, `{a:'build'|'discard', slot}`, `{a:'wonder', slot, wonder}`, `{a:'token', token}`, `{a:'destroy'|'steal', card}`. Duplicate `id` is ignored (resend after reconnect).
- `ki.js` (ES module): imports card data straight from `/mafia/worker/src/kurczacze/data.js` (Pages serves it, one source of truth), `Game` connection class (hello, reconnect, resend of an unconfirmed move), `createRoom({bot?})`, `BOT_LEVELS`/`botLevelName`, `inviteUrl()`, `seat`/`nick` storage (`kurczacze_p<slot>_<CODE>`, `kurczacze_nick`), `costText()`.
